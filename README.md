# random-coffee-bot

По субботам в 12:00 присылает в чат опрос "Участвуешь в Random Coffee на этой неделе?".
По понедельникам в 10:00 собирает всех, кто проголосовал "Да", случайно разбивает на пары
(или тройку, если участниц нечётное число) и публикует результат в чате.

## Переменные окружения (задать в панели Bothost → Environment Variables)

| Переменная       | Значение                                                              |
|------------------|------------------------------------------------------------------------|
| `BOT_TOKEN`      | токен этого бота от @BotFather                                        |
| `GROUP_CHAT_ID`  | ID группы, напр. `-1004364299105`                                     |
| `ADMIN_USER_ID`  | твой личный Telegram user_id (нужно для команды `/pick`)               |
| `GROUP_TOPIC_ID` | ID темы "Random Coffee" в группе, напр. `3123` (оставь пустым для главной темы) |

## Команды

- `/coffee_now` — вручную отправить опрос вне расписания
- `/pairs_now` — вручную запустить распределение пар
- `/pick` (только админ) — заранее выбрать себе пару на неделю (reply на сообщение участницы, или `/pick 123456789` в личке)
- `/topicid` — написать в любой теме группы, бот ответит её ID

## Деплой на Bothost

1. Залить этот репозиторий на GitHub (публичный, секретов внутри нет)
2. Bothost → Создать проект → Python → указать ссылку на этот репозиторий
3. Проставить переменные окружения из таблицы выше
4. Подключить постоянный диск (Volume) для файла `coffee.db`, если это не включено по умолчанию — иначе список проголосовавших будет обнуляться при каждом перезапуске
5. Запустить проект

Подробная общая инструкция (создание ботов у BotFather, получение ID) — в [../README.md](../README.md).
